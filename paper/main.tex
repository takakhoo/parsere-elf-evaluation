\begin{abstract}
Annotating basic blocks of an unknown binary with semantic labels is useful for reverse engineering, and much of that semantic information can be derived from the inputs the basic blocks process.
We present a technique for annotating binary implementations of known input formats with labels that reflect the input grammar.
The technique transfers annotations from inputs to programs by discovering execution trace differences and interpreting them in the context of the input annotations.
The analysis runs in time comparable to the initial analysis pass of reverse engineering tools such as Ghidra, and reveals the structure of complex parser code in a fraction of the time required by manual inspection.
Prior approaches to similar problems require instrumentation of the target program or dataflow analysis.
Our technique requires only basic-block traces from the target along with a corpus of annotated inputs.

We evaluate the accuracy of \toolname on parsers for four data formats spanning the language hierarchy: URI (regular), JSON (context-free), HPACK (context-sensitive binary), and ELF (offset-driven binary).
On the completed ELF evaluation, manual inspection of every label yields a strict accuracy of 91.2\%.
